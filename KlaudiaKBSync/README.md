# Klaudia KnowledgeBase Sync

Klaudia KnowledgeBase Sync is a standalone integration designed to synchronise external knowledge base content into Komodor’s Klaudia knowledge layer. The goal of this project is to make it easier to keep operational, platform, service, or customer-specific documentation available to Klaudia without requiring manual updates inside Komodor. This can help teams improve the quality and consistency of AI-assisted troubleshooting by ensuring Klaudia has access to relevant, up-to-date context.

The integration has been implemented in a dedicated repository:
[davidcollom/komodor-klaudia-sync](https://github.com/davidcollom/komodor-klaudia-sync)

An end-to-end usage example is also available, showing how the sync process can be configured and used in practice:
[davidcollom/komodor-klaudia-sync-example](https://github.com/davidcollom/komodor-klaudia-sync-example)
